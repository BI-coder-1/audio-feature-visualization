# 进阶音频分析原理

## 1. 为什么增加这些特征

原有幅值、平均能量和 RMS 主要回答“整段声音总体有多强”。进阶分析继续回答三个问题：声音强弱怎样随时间变化、频率能量集中在哪里、短时频谱包络是什么形状。它们属于经典信号处理，不依赖训练语音识别模型。

## 2. 分帧

语音和环境声音通常不是稳定不变的。程序使用 25 ms 帧长和 10 ms 帧移，把长波形切成许多重叠短帧。帧长为 25 ms 时，在 16 kHz 采样率下每帧包含：

```text
16000 × 0.025 = 400 个采样点
```

帧移为 10 ms，即相邻帧向前移动 160 个采样点。重叠可以减少相邻分析结果的突变。

## 3. 短时能量

每一帧的短时能量采用采样值平方的平均：

```text
E = mean(x[n]²)
```

平方使正负幅值不会相互抵消。能量曲线的峰值通常对应较强的发音、冲击或其他高能事件，但它不能单独判断事件是什么。

程序还计算“相对高能帧占比”：能量不低于本文件最大帧能量 10% 的帧数占全部帧数的比例。这只是文件内部相对指标，不等同于通用语音活动检测器。

## 4. 过零率

相邻采样点符号发生变化记作一次过零。每帧过零率为：

```text
ZCR = 过零次数 / (帧采样点数 - 1)
```

高频或噪声成分通常产生更多过零，低频周期信号通常产生较少过零。但过零率会受直流偏置和噪声影响，因此需要与能量、频谱共同解释。

## 5. 频谱统计量

- 主频：去除直流后功率最大的频率点。
- 频谱质心：以功率为权重的频率平均值，可理解为频谱的“重心”。
- 频谱带宽：各频率到质心距离的功率加权标准差。
- 85% 滚降点：累计功率达到总功率 85% 时对应的频率。
- 频谱平坦度：功率谱几何平均与算术平均的比值。接近 0 更像集中谱线，较大时更接近平坦噪声谱。

主频只是整段信号的最强频率，不自动等于人的基频，也不代表语音内容。

## 6. MFCC

MFCC 是 Mel 频率倒谱系数，计算顺序如下：

1. 对每帧做预加重，让高频信息不过度被低频掩盖。
2. 乘 Hamming 窗，减小直接截断造成的频谱泄漏。
3. 使用 FFT 得到每帧功率谱。
4. 用 26 个 Mel 三角滤波器汇总频带能量。
5. 对 Mel 能量取自然对数。
6. 使用离散余弦变换压缩相关性，保留前 13 个系数。

MFCC 热力图横轴是时间，纵轴是系数编号，颜色表示系数值。它概括短时频谱包络和音色变化，但本项目不把 MFCC 输入分类器或识别模型。

## 7. 测试如何证明实现正确

`test_advanced_features.py` 使用已知 1000 Hz 正弦波验证：主频、频谱质心和 85% 滚降点应接近 1000 Hz；理论过零率约为 `2 × 1000 / 16000 = 0.125`；MFCC 必须为 13 行且所有数值有限。静音测试要求所有汇总特征为 0，避免除零或对数异常。

## 8. 比较时必须保留的边界

- 所有比较都是描述性信号特征比较，不代表识别出了说话人、语义或声音类别。
- 录音增益、麦克风距离和设备不同都会改变幅度与能量，不能把差异直接解释为内容差异。
- 主频是整段功率谱的最强频率，不自动等于人的声带基频。
- MFCC 描述短时频谱包络；不同采样率、录音带宽和噪声条件会影响其数值。
- 总能量受音频时长影响。跨文件比较应优先结合平均能量、RMS、时长和频谱指标共同判断。

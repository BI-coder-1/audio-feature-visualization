# 交互式网页说明

## 1. 功能定位

网页是现有课程项目的交互入口，不另写一套音频算法。用户在浏览器选择 WAV 文件后，Flask 接收文件，再调用 `src` 中已经验收的读取、特征计算、频谱绘制和 STFT 绘制函数。

## 2. 启动方法

```powershell
python -m web_app
```

浏览器打开 `http://127.0.0.1:5000`。默认只监听本机地址，局域网和互联网中的其他设备不能直接访问。

## 3. 一次请求的处理顺序

1. 浏览器使用 `multipart/form-data` 上传 WAV 文件。
2. Flask 检查是否选择文件、扩展名是否为 `.wav`、文件是否超过 12 MB。
3. `TemporaryDirectory` 创建只服务于本次请求的临时目录。
4. `load_wav()` 读取音频并生成 `AudioSample` 对象。
5. `extract_basic_features()` 计算八项时域特征。
6. `plot_audio_overview()` 生成波形和单边频谱图。
7. `plot_stft_overview()` 生成时域波形和 STFT 声谱图。
8. 图片和音频被 Base64 编码后嵌入结果页面。
9. 离开 `with` 代码块后，临时目录及上传文件自动删除。

## 4. 为什么使用 Base64

浏览器通常通过 URL 请求图片和音频。但本项目不保存用户文件，因此不能在分析结束后继续提供一个磁盘文件 URL。Base64 会把二进制内容转换成文本并放进 HTML 的 data URL，页面拿到响应后即可直接显示。代价是响应体会变大，所以网页设置了 12 MB 的上传上限。

## 5. 安全边界

- 只接受 `.wav` 扩展名，文件内容仍由 SciPy 验证。
- `secure_filename()` 清理文件名，避免用户文件名被解释为目录路径。
- 上传内容写入系统临时目录，不写入项目的 `data`、`samples` 或 `results`。
- 默认只监听 `127.0.0.1`，适合课程演示，不等同于生产服务器。

## 6. 页面设计说明

页面借鉴高校官网常见的信息层级：顶部辅助导航、深蓝色主导航、宽幅主视觉和分区内容模块。项目没有复制山西大学校徽、照片或其他官方素材，也不代表山西大学官方网站。

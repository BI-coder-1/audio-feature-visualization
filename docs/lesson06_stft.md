# 第六课时：STFT 与声谱图学习说明

## 1. 为什么整段FFT无法描述时间变化？
整段FFT把整段信号作为一个整体进行频域变换，能够描述全局频率组成，但不能定位某个频率在什么时间出现。它不是对时间轴求平均。

## 2. STFT为什么要分帧？
为了捕捉时间信息，STFT 把长音频切成很多短帧，每一帧单独做 FFT。这样就能得到“特定时间对应的特定频率”，从而展现声音随时间的动态变化。

## 3. 为什么使用Hann窗？
如果不加窗直接截断，帧首尾会产生突变，导致能量向相邻频率格点扩散（频谱泄漏）。Hann 窗能让首尾平滑过渡到 0，减少这种泄漏。

## 4. 窗长对时间、频率分辨率有什么影响？
窗长越长，频率分辨率越高，但时间分辨率越差；窗长越短，时间定位越准，但频率分辨率越差。这就是经典的“测不准原理”。

## 5. 为什么帧之间需要重叠？
重叠能让每一帧的交界处更加平滑，避免因为切分导致帧边界的信息丢失，让生成的热力图更连续。

## 6. STFT为什么得到复数？
STFT 本质上是多次 FFT。FFT 的结果是复数，包含了“幅度”（这个频率有多响）和“相位”（这个频率的波走到哪了）两部分信息。

## 7. 为什么取绝对值？
我们画声谱图关注的是“音量大小”（幅度），而不是波的相位。所以用 np.abs() 取绝对值，把复数变成实数。

## 8. 为什么转换为dB？
人耳对声音的感知是对数级的，而且绝对幅度的数值范围很大，直接画图很难看清细节。转换为 dB 后，能够将动态范围压缩，让弱小的声音细节也能在图上显示。

## 9. 为什么设置 -80 dB 下限？
-80 dB 是本系统设置的相对显示下限，用于避免零幅度产生负无穷，并保持不同图像使用一致的颜色范围。它不是物理声压级，也不代表固定的听觉阈值。

## 10. 图中能客观观察到什么？
在当前 0_0_1.wav 的声谱图中，我们可以看到在 3.3 秒左右，出现了一组横跨极低频到中频的明亮亮斑。这说明在这一瞬间，该文件在较宽的频率范围内产生了较强的相对频谱幅度。

## 11. 为什么不能从一张声谱图判断具体故障类别？
因为一个样本无法代表整个类别，且不同的故障或环境变化可能产生相似的频谱特征。具体成因需要依赖更多样本、分类标签以及更深入的声学分析。

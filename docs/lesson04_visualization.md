# 第四课时：时域波形与频谱可视化学习说明

## 1\. 采样点如何转换为时间

通过 np.arange(num\_samples) / sample\_rate，生成从 0 到 4.9999375 秒的时间轴。
第 n 个采样点对应的时间为 t\_n = n / f\_s。

## 2\. 为什么时间轴最后不是恰好5秒

因为采样点是从 0 开始的索引，5 秒对应第 80000 个点，而最后一个点的索引是 79999，计算得 79999 / 16000 = 4.9999375 秒。

## 3\. 时域和频域分别表示什么

时域描述信号幅度随时间的变化（能看到声音大小起伏）；频域描述信号包含哪些频率成分及它们各自的强度（能看到音调的高低）。

## 4\. FFT和rfft的区别

FFT 计算所有频率（包括负频率），rfft 针对实数信号，仅计算非负频率（0到奈奎斯特频率）。rfft 计算量更小，适合本项目的音频数据。

## 5\. 奈奎斯特频率的含义

根据采样定理，能还原的最高频率是采样率的一半。本项目采样率 16000 Hz，因此最高频率是 8000 Hz。

## 6\. 为什么频率范围是0～8000 Hz

因为采样率是 16000 Hz，根据奈奎斯特定理，最高有效频率为 8000 Hz。

## 7\. 为什么FFT前减去均值

减去均值可以消除音频中的直流偏移（0Hz分量）。如果不减，频谱图在 0Hz 处会出现一个巨大的尖峰，导致其他频率的特征被严重压缩。

## 8\. 单边幅度谱为什么需要归一化

因为直接做 FFT 算出的幅度与采样点数成正比。除以采样点数并乘以 2（非直流和非奈奎斯特频率），可以还原成相对真实的物理幅度。

## 9\. 当前未使用窗函数带来的频谱泄漏限制

直接对整段信号做 FFT，如果不加窗，信号两端会被突然截断，导致原本集中的能量向周围频率泄漏，频谱图上会出现很多毛刺，不能完全反映真实频率分布。

## 10\. 图中能观察到什么（仅限当前文件）

在 0\_0\_1.wav 的图中，能看到明显的高低起伏的时域包络；频谱图上呈现低频能量较高、高频能量逐渐衰减的趋势。这反映了船舶低频机械声的特征。暂不由此推断整个类别。

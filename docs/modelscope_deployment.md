# 魔搭创空间部署与验收手册

## 1. 这次改造解决什么问题

原来的 Streamlit 页面已经可以分析 WAV，但此前文档面向 Streamlit Community Cloud。魔搭创空间的 Streamlit 模式要求根目录提供 `app.py`，所以本次新增一个很薄的启动入口，并把页面主体继续保留在 `streamlit_app.py`。

程序启动关系如下：

```text
魔搭 Streamlit 运行器
        ↓
根目录 app.py
        ↓ 调用 main()
streamlit_app.py
        ↓ 调用
web_app/streamlit_support.py
        ↓ 调用
src/ 中的音频读取、特征和绘图函数
```

这种分层没有改变音频计算公式，只改变了公网平台如何找到页面入口。

## 2. 创建创空间时怎样填写

1. 打开 `https://modelscope.cn/studios`，登录后点击“我要创建”。
2. 名称建议填写 `sxu-audio-analysis-202501071025`。
3. 简介可以填写“山西大学人工智能学院 Python 课程设计：WAV 音频特征分析与可视化”。
4. 第一次部署先选择私有，验收完成后再改为公开。
5. 应用部署框架选择 **Streamlit**。
6. 云资源选择 **免费 CPU**。
7. 镜像选择平台当时标记的推荐版本，不手动选择 Docker。

免费 CPU 足以运行本项目的 NumPy、SciPy 和 Matplotlib 分析，但空闲后可能休眠。Docker 和付费资源不是本项目的必要条件。

## 3. 怎样把 GitHub 代码放进创空间

优先使用创建页面提供的“从 GitHub 获取”或“拉取代码”功能，仓库填写：

```text
https://github.com/BI-coder-1/audio-feature-visualization
```

分支选择 `main`。如果页面只提供“通过 Git 上传”，请使用创空间管理页显示的仓库地址和命令；不要把访问令牌写入代码、README、截图或 Git 远端地址后提交。

上传完成后至少检查这些路径存在：

```text
app.py
streamlit_app.py
requirements.txt
.streamlit/config.toml
src/
web_app/
```

`samples/` 只用于自动测试，用户在网页上传的文件不会保存到该目录。

## 4. 部署时每个文件做什么

- `app.py`：魔搭首先运行的入口，只调用页面的 `main()`。
- `streamlit_app.py`：标题、作者标识、上传控件、结果表格和图片布局。
- `requirements.txt`：告诉云端安装哪些 Python 第三方库及其版本。
- `.streamlit/config.toml`：设置主题、关闭遥测并限制单文件最大 12 MB。
- `web_app/streamlit_support.py`：校验上传、创建临时目录、调用算法并把结果读回内存。
- `src/`：真正的 WAV 读取、17 项特征、MFCC、STFT 和绘图算法。

## 5. 第一次部署怎样验收

部署成功后不要只看首页，按以下顺序逐项检查：

1. 首页能看到“语音信号分析与可视化系统”。
2. 作者区域显示“山西大学人工智能学院、2501、侯世俊、202501071025”。
3. 上传 `samples/0_0_1.wav`，点击“生成深度分析结果”。
4. 页面显示采样率、声道数、采样点数和时长。
5. 页面能播放音频，并显示 17 项特征。
6. 波形与频谱、STFT、短时特征与 MFCC 三张图都能打开。
7. 单文件 CSV 可以下载并被 Excel 正确打开。
8. 切换“双文件特征比较”，再上传 `samples/4_0_1.wav`。
9. 比较表、比较图和双文件 CSV 均能生成。
10. 查看运行日志，没有红色异常或依赖安装失败。

全部通过后，把创空间可见性改为公开，并复制平台给出的实际链接。不要提前猜测链接是否已经被占用。

## 6. 常见错误怎样判断

### 页面提示找不到 `app.py`

说明上传的不是仓库根目录，或创空间仍在旧提交。确认 `app.py` 与 `requirements.txt` 位于最外层，然后重新部署。

### 依赖安装失败

先看日志中第一个报错的包。确认使用平台推荐镜像，并检查 `requirements.txt` 是否完整；不要通过反复删除依赖来掩盖错误。

### 页面能打开但分析时报错

先用仓库内两个小样本复现。若小样本正常，通常是用户文件格式、文件大小或 WAV 编码问题；页面会拒绝空文件、非 `.wav` 文件和超过 12 MB 的文件。

### 首次访问很慢

免费 CPU 空闲后可能进入休眠，第一次重新访问需要等待启动。这不等于程序计算公式出错。

## 7. 安全与归属边界

- 不要上传机密、隐私或无权处理的录音。
- 临时文件在单次分析函数结束后删除，但平台仍会接收上传字节。
- 学院、班级、姓名和学号用于课程作品归属标识，不等同于专利授权或软件著作权登记。
- 本项目不训练语音识别模型，也不识别说话人身份。

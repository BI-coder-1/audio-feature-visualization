# 高分扩展与评分点映射

| 扩展功能 | 对应课程能力 | 可演示证据 |
|---|---|---|
| 短时能量与过零率 | 提高功能、短时信号分析 | 三联时序曲线、数值特征、独立测试 |
| 五项频谱统计 | FFT 结果的定量解释 | 主频、质心、带宽、滚降点、平坦度 |
| 13 维 MFCC | 经典语音特征提取 | MFCC 热力图、分步骤实现与维度测试 |
| 双音频完整比较 | 题目必做的不同文件比较 | 网页表格、柱状图、比较 CSV |
| CSV 下载 | 结果可复核与报告制作 | 单文件和双文件导出按钮 |
| 临时文件与异常检查 | 工程规范和安全性 | 格式/大小检查、自动删除、错误测试 |
| Flask + Streamlit 双入口 | 软件分层、复用与部署能力 | 本地教学版、公网展示版、统一算法与独立回归测试 |

答辩时应先解释算法意义和数学计算，再展示网页。网页是交互入口，不是项目的主要技术贡献。
